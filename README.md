# JobTest

JobTest will be a web app that administers the retired O*NET® Ability Profiler™, scores results, and suggests jobs.

This repository currently holds the official archived source materials and project docs only. The web app itself is not started yet.

The Ability Profiler was a career exploration tool from the U.S. Department of Labor. It was retired on November 20, 2021. The files in `source/` come from the official archive:

- [O*NET Ability Profiler Archived Materials](https://www.onetcenter.org/reports/AP_Archive.html)

Those materials are provided “AS IS” for research purposes. Technical assistance is no longer available from O*NET.
